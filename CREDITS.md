# Credits

BlindTerm keeps ordinary terminal output as a readable transcript in a native edit control, so NVDA and JAWS can navigate it by line, word, and character. When a full-screen program (nano, vim, htop, less, an editor over SSH) takes over, keys go to the program and speech follows the cursor instead of reading every repaint.

Third-party works it stands on:

- ConPTY (Windows pseudoterminal) for running shells.
- The bundled NVDA controller client, which stays under its own LGPL license (see `native\nvdaControllerClient-LICENSE.txt`).
- MUD directory sources for the MUD list: MUDVerse, MUDStats, Grapevine, The Mud Connector, and GMUD. The generated directory lives in [BlindTerm-directory](https://git.serrebiradio.com/serrebi/BlindTerm-directory).

Questions and bug reports are welcome in the [SerrebiProjects Telegram group](https://t.me/SerrebiProjects). More serrebi projects: [projects.serrebiradio.com](https://projects.serrebiradio.com).
